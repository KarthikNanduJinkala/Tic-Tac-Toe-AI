# Tic-Tac-Toe-AI
AI-powered Tic-Tac-Toe game using Python

Tic-Tac-Toe AI

Project Overview

This project is an AI-powered Tic-Tac-Toe game developed using Python.

Objective

To create an intelligent opponent that makes strategic moves against the player.

Technologies Used

- Python
- Artificial Intelligence
- Minimax Algorithm

Features

- Interactive Tic-Tac-Toe game
- AI-based decision making
- Win, lose and draw detection

Result

The AI successfully plays the game and can produce a tie result.
